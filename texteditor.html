This editor allows you to edit the content (title, meta, body text, images, videos, etc.) while keeping the overall structure and styles fixed. Use the rich text editor for the body to add paragraphs, headings, quotes (via blockquote), images, and video URLs (which will embed as iframes for supported platforms like YouTube).
