# Page Descriptions

This document provides a short description of each page in the Concept Builders web application.

## Public Pages

| Page | Description |
|---|---|
| `/` | The home page of the application. |
| `/about` | The about page, providing information about the company. |
| `/auth` | The authentication page, for logging in and signing up. |
| `/auth/reset-password` | The page for resetting a user's password. |
| `/blog` | The blog page, listing all blog posts. |
| `/blog/[slug]` | The detail page for a specific blog post. |
| `/cart` | The user's shopping cart. |
| `/checkout` | The checkout page, for completing a purchase. |
| `/contact` | The contact page, with a form for sending messages to the admin. |
| `/cost-calculator` | A tool for calculating the cost of a building project. |
| `/currency-converter` | A tool for converting between different currencies. |
| `/custom-design` | A form for requesting a custom design. |
| `/custom-design/[id]` | The detail page for a specific custom design request. |
| `/design-showcase` | A page for showcasing designs. |
| `/designs` | The main page for browsing all designs. |
| `/designs/[id]` | The detail page for a specific design. |
| `/faq` | The frequently asked questions page. |
| `/maintenance` | A page to show when the site is down for maintenance. |
| `/ongoing-projects` | A page listing all ongoing projects. |
| `/ongoing-projects/[slug]` | The detail page for a specific ongoing project. |
| `/paypal-test` | A page for testing PayPal payments. |
| `/privacy` | The privacy policy page. |
| `/purchase-confirmation` | The page shown after a successful purchase. |
| `/refund` | The refund policy page. |
| `/terms` | The terms of service page. |
